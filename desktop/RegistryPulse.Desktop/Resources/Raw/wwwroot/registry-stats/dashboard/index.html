Registry Pulse is a local, file-based dashboard for multi-registry package metrics.
Setup: define portfolio, generate snapshot.
Dashboard: view summary, breakdown, leaderboard.
Data: stored locally on Desktop; static JSON on web.
Registries: npm, PyPI, NuGet, VS Code Marketplace, Docker Hub, GitHub Releases.
Privacy: no telemetry and no accounts. The portfolio stays in local files. Refresh reads public registry data and does not upload the portfolio. The assistant sends the injected snapshot through the local Ollama daemon, which can proxy a cloud model.

📖 How to use this dashboard

Quick start

  1. Set up your portfolio — on the Setup page, edit the JSON arrays in packages.json: npm, pypi, vscode, nuget, docker, and github, plus an optional npmMaintainer string. This file is not registry-stats.config.json. Put one package name on each line inside the array for that registry, then save. A non-empty npmMaintainer calls stats.mine and adds discovered names that are not already in the npm array. If discovery throws, the site fetch warns and keeps the explicit npm list.
  2. Wait for data — registry-stats fetches download counts from npm, PyPI, VS Code Marketplace, NuGet, Docker Hub, and GitHub Releases. The first snapshot takes about a minute.
  3. Explore the tabs — Home has the AI chat assistant, Analytics shows charts and insights, and Leaderboard ranks every package.

What each tab does

🏠 Home

The landing view with the executive snapshot (health score, npm weekly change, diversity, coverage) and the summary cards. Weekly and monthly downloads on those cards are npm and PyPI. The Registry Assistant is an AI chat (Ollama, on this machine. It starts on a local model) that can answer questions about your data.

📊 Analytics

Seven interactive charts: 30-Day Trend (toggle between aggregate, per-registry, and top-5 views), Registry Share (polar area), Portfolio Risk (distribution histogram with Gini & P90), Top 10 Momentum (bar chart colour-coded by velocity), Velocity Tracker (sparkline list sorted by growth rate), 30-Day Heatmap (per-package daily grid with spike detection), and Portfolio Trend (stacked area of the weeks tracked).

🏆 Leaderboard

Sorted by the Downloads column. npm and PyPI are the week. VS Code, NuGet, Docker, and GitHub are all-time. Month is npm and PyPI. The 30-day sparkline is the npm series; other rows show an em dash. Trend is last 7 versus the prior 7, npm only, and the badge avoids misleading percentages for low-volume packages.

Key concepts

Smart Growth Engine
Percentages can be misleading when the previous count is tiny (e.g., 2 → 50 = +2,400%). When the prior period is below 20 downloads the badge shows 🚀 Emerging instead of a raw percentage. Growth above 500% is capped and the real delta is shown alongside.
Velocity Score
A damped growth metric: (curr − prev) / √(prev + k). It rewards genuine acceleration while keeping tiny-base packages from dominating. Used in Momentum, Velocity Tracker, and Leaderboard columns.
Spike detection (>2σ)
On the heatmap, any day where a package’s downloads are more than two standard deviations above its 30-day mean is flagged with an amber dot. The “Spikes Only” toggle dims everything else so anomalies stand out.
Health Score (0–100)
A composite index combining registry coverage (how many sources responded), error count, week-over-week growth direction, and Shannon diversity (how evenly downloads spread across registries).
Confidence badges
The marks are on the Data Health rows. ✅ ok means every package in that registry came back from this fetch. ⚠️ partial means some failed or were filled from the previous snapshot. ⛔ means nothing came back, or the portfolio lists no packages for that registry.

AI Inference Engine

The Analytics tab includes a built-in inference engine that runs at build time — no ML runtime, no external APIs, pure math. It powers these capabilities:

7-Day Forecast
Weighted linear regression with exponential recency bias. Recent downloads matter more than older data. Includes 80% confidence intervals that widen further into the future.
Anomaly Detection
Adaptive rolling z-score with a 14-day baseline window. Detects both spikes and drops, reporting the expected value and deviation magnitude. Avoids seasonal false positives by using a rolling window instead of global statistics.
Portfolio Momentum (−100 to +100)
A composite score combining trend direction, acceleration (change in slope), consistency (how uniform the direction is), and volume weighting. Positive = growing portfolio, negative = declining.
Automated Recommendations
The engine generates prioritised recommendations across four types: growth (high-momentum packages), risk (concentration, npm-dependence), opportunity (under-diversified registries), and attention (declining packages needing review).
Package health grades
A 0–100 score from activity, consistency, growth, and stability, with an A–F letter grade per package.
Actionable advice
Severity-tagged cards (critical, warning, info, success) with an urgency level and a specific next step for the packages named on the card.

Using the AI assistant

The Registry Assistant on the Home tab talks to a local Ollama instance on localhost:11434. It automatically injects a snapshot of your registry data into every prompt so the model can answer questions like:

  • “Which package grew the fastest this week?”
  • “Summarise the npm vs PyPI split.”
  • “Why did site-theme spike on day 27?”

Local model. The picker starts on a model installed on this machine. If Ollama is offline the chat shows a fallback, and the rest of the dashboard still works.

How data flows

The pipeline runs each time you build the site (or on a schedule in CI):

packages.json→fetch providers→inference engine→stats.json→Astro build→static HTML

The site fetch walks the six registries one after another: npm (weekly + 30-day range), PyPI (weekly), VS Code Marketplace (installs), NuGet (total), Docker Hub (pulls), and GitHub Releases (owner/repo, cumulative asset downloads). Each provider has retries with exponential back-off. The tracked list is site/src/data/packages.json.
